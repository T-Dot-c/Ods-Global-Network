1 Interactive Credential Recovery Pipeline

State-of-the-art authentication lifecycle designed to prevent credential enumeration, secure transport tokens, and provide seamless user feedback.

Step 01

Forgot Password

User inputs email. Rate limit of 20 req/15m enforced. RFC 5322 regex checks syntax.

Route: /forgot-password
Step 02

Anti-Enumeration

API returns exact identical HTTP 200 whether email exists or not. Zero reconnaissance leaks.

Uniform HTTP 200
Step 03

PostgreSQL OTP

Generates cryptographically random 6-digit OTP. Hashed with bcrypt into otp_codes table (15m expiry).

Table: otp_codes
Step 04

In-Memory Route

Email moves to Reset Password view via in-memory React state. Zero query parameters in URL.

Memory State Only
Step 05

Bcrypt 12 Reset

User enters code + new password. Password hashed with 12-round bcrypt. OTP marked consumed.

ACID Transaction

3 Backend Endpoints & PostgreSQL Integration

High-performance Express.js endpoints backed by PostgreSQL 18.6 relational tables with ACID transaction rollbacks.

POST /api/auth/forgot-password

Initiates recovery request and issues time-limited OTP.

  • RFC 5322 regex email sanitization
  • Invalidates existing pending OTPs for the user
  • Saves bcrypt hash into otp_codes (15m expiry)
  • Uniform neutral JSON response for anti-enumeration

POST /api/auth/reset-password

Validates code and commits 12-round bcrypt password hash.

  • Atomic database transaction (BEGIN / COMMIT)
  • Bcrypt comparison against stored code_hash
  • Resets failed_login_attempts = 0 & locked_until = NULL
  • Marks OTP consumed with verified_at = now()

Dynamic Dev CORS Middleware (server.js)

Configured with dynamic origin resolution supporting http://localhost:5173, http://127.0.0.1:5173, and secondary Vite ports (5174–5176), eliminating preflight CORS blockage.
